# Лабораторная работа №2 — Web-сайт «PaintRent»

**Тема:** сервис по аренде картин.

**Цель:** изучение основ HTML и CSS.

**Технологии:** HTML5, CSS3. Без JavaScript, Bootstrap и других библиотек и фреймворков.

## 📁 Структура проекта

```text
├── lab2/
│   ├── css/
│   │   └── style.css      # Основные стили оформления
│   ├── catalog.html       # Страница каталога товаров
│   ├── contacts.html      # Страница с контактной информацией
│   ├── index.html         # Главная страница проекта
│   └── prices.html        # Страница с прайс-листом и ценами
└── README.md              # Документация проекта
```

## Запуск проекта

### Локальный запуск (в браузере)
1. Склонируйте репозиторий или скачайте архив с файлами.
2. Перейдите в папку `lab2`.
3. Дважды кликните по файлу `index.html` — проект откроется в вашем браузере по умолчанию.

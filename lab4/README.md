## Лабораторная работа № 4

**Ветка:** `lab4`

**Что сделано:**
- Вёрстка главной страницы (`index.html`) — Flexbox
- Вёрстка каталога (`catalog.html`) — CSS Grid (auto-fit / minmax)
- Все цвета вынесены в CSS-переменные (`css/variables.css`)
- CSS-анимация: плавающие «блобы» в hero-секции (@keyframes float-blob)
- Форма заявки на аренду (`contacts.html`) — 5 типов полей: text, email, tel, select, checkbox
- JavaScript-класс `RentalRequest` (`js/form.js`) с конструктором и методом `print()` — выводит данные в консоль при отправке формы
- БЭМ-нейминг классов на всех страницах

**Как проверить:**
1. Открыть `lab4/index.html`.
2. Открыть `lab4/contacts.html`, заполнить форму, нажать «Отправить заявку», открыть DevTools Console (F12).
